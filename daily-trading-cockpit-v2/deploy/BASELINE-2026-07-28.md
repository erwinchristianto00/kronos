measure, and that is what this file records.

## What the 413 "dirty" entries on 3101 were

Not unhandled work. Every differing file there is a **strict subset** of HEAD — content that HEAD
has since extended or renamed. Checked file by file: `paper-execution-router.ts` was 7,758 lines
against HEAD's 7,817 with **zero** lines unique to the box, and the three test files that matched no
commit at all (`live-execution-engine.test.ts` 3,799 vs 5,983, `single-symbol-lane-executor.test.ts`
624 vs 1,463, `crisis-mode-cycle.test.ts` 437 vs 478) differed only by test titles that HEAD renamed.

So 3101 can be brought to HEAD by overwriting. Nothing is lost.

The 9 duplicates were byte-identical copies of files already tracked in `apps/api/scripts/`, and in
`src/` they sat inside the surface `tsconfig.json` compiles; `current-guard-variant-matrix.ts:601,609`
names two of them at their `scripts/` path. Live's copies, and its
`src/lib/wallet-reconciliation.pre-directional-deploy.ts`, had already been removed by the concurrent
agent before this pass — only stale `dist/` output for that module remains, which nothing executes
(`deploy/run-api.sh` runs `npx tsx src/server.ts`, checked rather than assumed).

Two traps worth keeping:

- `find -delete` implies `-depth`, which silently defeats `-prune`. It reports success and deletes
  nothing. Delete from an explicit list.
- The `data/*.json.bak` files are **not** litter — they are the stores' own atomic-write backups.
  Left in place: 3 on 3101, 4 each on 3102 and 3103.

Everything was tarred to `/tmp/{live,testnet}-junk-backup-20260728.tgz` before deletion. Afterwards all
three typecheck with 0 errors **on the server**, all three answer 200, and live is still
`armed=false` with 0 positions and 0 orders. No instance was restarted — nothing imported any of it.

## Porting into 3103

Diff against `46a2112` per file, not against `git status`, and not by copying whole directories:
live's router is a genuinely older base, not a variant carrying unique work — but that claim is only
verified for 3101, so re-run the subset check on live before overwriting anything there. Deploying a
file also deploys its imports: enumerate them and confirm each exists on the target, typecheck **on
the server**, then restart, then confirm `/api/health` returns 200. A deploy is not finished at rsync.
